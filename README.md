# DevInsights
### Github repository Analyzer tool that turns raw repo data into Insights.   
> Every repo tells a story.

DevInsights analyzes Github repositories and transforms raw 
repository data into insights.

Originally built as a hackathon project and later redesigned 
and extended into a complete developer-focused analysis tool

## Features
- Repository analytics
- Commit activity
- Contributor insights
- Language Composition
- PDF audit report
- Live Github REST API data
